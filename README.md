# slurpsmcgoo-scratch

Scratch projects, one per top-level folder. Each has its own README with setup steps.

| Project | What it is |
|---|---|
| [`halloween/`](halloween/) | A browser app that rear-projects reactive Halloween scenes onto a sheet in a front window, driven by a webcam, microphone, simulator or replayed logs. |
| [`kubb_game/`](kubb_game/) | Kubb, the Viking lawn game, in 3D in the browser: real physics, teams, computer players, online play peer to peer, a park and the Moon. |

Working with coding agents: see [`CLAUDE.md`](CLAUDE.md) for the repo-wide rules. Shared agent permissions live in [`.claude/settings.json`](.claude/settings.json).
